# 📚 Study Planner

An offline-first desktop study planner built with **Python and Tkinter** to help students organize their academic tasks, subjects, deadlines, and priorities in one place.

## ✨ Features

- 📝 Add, complete, and delete tasks
- 📚 Add and manage subjects
- 📅 Select task deadlines using a calendar
- 🔴 Set task priority: High, Medium, or Low
- ⏰ Automatic deadline reminders
- 📊 Dynamic task summary
- 💾 Local data persistence using JSON
- 📜 Scrollable task list
- 🧹 Clear completed tasks
- 🖥️ Standalone Windows `.exe` version

## 🛠️ Technologies Used

- **Python**
- **Tkinter**
- **tkcalendar**
- **JSON**

## 🎯 Project Idea

Study Planner was created as a personal academic companion — a simple digital alternative to maintaining a traditional study diary.

The application is designed to work **offline**, keeping student data stored locally on the computer.
